About


The Isensix Calibration Dashboard is a work in progress tool to visualize multiple Isensix servers simultaneously to monitor, validate, summarize, and improve efficiency of the Isensix calibration process. In combination with tampermonkey scripts, the data on this page will update automatically after every calibration. It will eventually replace the Google Sheets based tool.
