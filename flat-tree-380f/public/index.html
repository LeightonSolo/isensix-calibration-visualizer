About the Calibration Dashboard

The Isensix Calibration Dashboard helps monitor, validate, summarize, and improve calibration work across multiple Isensix servers.

With the Leighton's Isensix Tools Chrome extension installed, dashboard data updates when you visit any of these pages on any Isensix server:

  • The Live View.
  • The calibration page, which shows immediately after calibrating a sensor.
  • The calibration summary page (sometimes called Amies Isensix Calibration Summary), or the debug query on ARMS servers.

If you are noticing any data missing from the dashboard, please view one of the pages above, then click refresh on the dashboard.

By Leighton Solomon
